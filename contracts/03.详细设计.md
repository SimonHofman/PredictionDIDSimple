## 1. 引言

### 1.1 编写目的

本文档在需求规格（01）与概要设计（02）基础上，给出 Smart Contracts 的**详细设计**：包括各合约状态变量、函数逐步逻辑、数学公式、事件 ABI 布局、跨合约调用链、部署脚本步骤与 revert 目录，供开发、审计、Indexer/Frontend 联调直接对照实现。

### 1.2 文档约定

- **路径**：除非注明，均相对于 `contracts/` 目录。
- **金额单位**：uint256 为 ERC20 **最小单位**；MockUSDC 为 6 decimals（1 USDC = `1e6`）。
- **地址**：`address(0)` 在 constructor 中被拒绝。
- **status 枚举**：Open=0、Resolved=1、Voided=2（与 `IPredictionMarket.status()` 一致）。
- **outcome**：二元市场 0=Yes、1=No；多结果市场为 `0 .. outcomeCount-1`。
- **Phase**：Phase 2 = parimutuel + OracleAdapter；Phase 3 = CPMM/Multi + OracleAdapterV2。

## 2. 接口与公共类型

### 2.1 IPredictionMarket

**文件**：`contracts/interfaces/IPredictionMarket.sol`

```solidity
interface IPredictionMarket {
    function status() external view returns (uint8);
    function resolve(uint8 winningOutcome) external;
    function voidMarket() external;
}
```

| 方法 | 调用方 | 前置条件 | 效果 |
|------|--------|----------|------|
| status() | view | — | 返回 0/1/2 |
| resolve(outcome) | oracle 或 Adapter 间接 | Open | → Resolved |
| voidMarket() | oracle 或 Adapter 间接 | Open | → Voided |

**实现合约**：

| 合约 | status() 实现 |
|------|---------------|
| PredictionMarket | 编译器生成 `Status public status` getter（enum → uint8） |
| PredictionMarketV3 | 显式 `return uint8(marketStatus)` |
| MultiOutcomeMarket | 显式 `return uint8(marketStatus)` |

**注意**：PredictionMarket **未** `implements IPredictionMarket`，但 public enum getter 与接口 ABI 兼容；OracleAdapter 通过接口指针调用。

### 2.2 公共 enum Status

所有市场合约使用相同三态（命名略有差异）：

| 值 | PredictionMarket | PredictionMarketV3 / MultiOutcomeMarket |
|----|------------------|----------------------------------------|
| 0 | Status.Open | Status.Open |
| 1 | Status.Resolved | Status.Resolved |
| 2 | Status.Voided | Status.Voided |

PredictionMarketV3 状态变量名为 `marketStatus`；PredictionMarket 为 `status`。

### 2.3 OpenZeppelin 依赖用法

| 库 | 使用合约 | 用途 |
|----|----------|------|
| SafeERC20 | PM, PMV3, Multi | transferFrom / transfer |
| ReentrancyGuard | PMV3, Multi | nonReentrant |
| Ownable | Factory, FactoryV3, DIDRegistry | onlyOwner |
| AccessControl | OracleAdapter, OracleAdapterV2 | ORACLE_ROLE / ADMIN |
| Pausable | MarketFactoryV3 | whenNotPaused |
| ECDSA + MessageHashUtils | DIDRegistry | bindDid 验签 |

### 3.2 PredictionMarket（Phase 2 二元 parimutuel）

**文件**：`contracts/PredictionMarket.sol`

#### 3.2.1 状态变量

| 名称 | 类型 | 可变性 | 说明 |
|------|------|--------|------|
| collateral | IERC20 | immutable | 抵押代币 |
| oracle | address | immutable | 结算/作废权限 |
| factory | address | immutable | 创建者工厂地址 |
| matchRef | bytes32 | immutable | 赛事引用哈希 |
| question | string | storage | 市场问题 |
| endTime | uint256 | storage | 下注截止 unix 秒 |
| status | Status | storage | Open/Resolved/Voided |
| winningOutcome | uint8 | storage | 结算结果 |
| yesPool / noPool | uint256 | storage | 两侧彩池总量 |
| yesBalance / noBalance | mapping(address=>uint256) | storage | 用户押注 |
| claimed | mapping(address=>bool) | storage | 是否已 claim |

#### 3.2.2 modifier onlyOracle

```
require(msg.sender == oracle, "not oracle")
```

#### 3.2.3 constructor

**签名**：`(collateral, oracle, factory, matchRef, question, endTime)`

**步骤**：

1. `require(_collateral != address(0), "collateral")`
2. `require(_oracle != address(0), "oracle")`
3. `require(_endTime > block.timestamp, "end in past")`
4. 赋值 immutable + question/endTime
5. `status = Open`

#### 3.2.4 buy(uint8 outcome, uint256 amount)

**步骤**：

```
1. require status == Open
2. require block.timestamp < endTime
3. require outcome <= 1
4. require amount > 0
5. collateral.safeTransferFrom(msg.sender, this, amount)
6. IF outcome == 0:
     yesBalance[sender] += amount; yesPool += amount
   ELSE:
     noBalance[sender] += amount; noPool += amount
7. emit Bought(sender, outcome, amount)
```

**Gas 相关**：单次 SSTORE 更新用户 balance + pool。

#### 3.2.5 resolve(uint8 _winningOutcome) — onlyOracle

```
1. require status == Open
2. require _winningOutcome <= 1
3. status = Resolved; winningOutcome = _winningOutcome
4. emit Resolved(_winningOutcome)
```

#### 3.2.6 voidMarket() — onlyOracle

```
1. require status == Open
2. status = Voided
3. emit MarketVoided()
```

#### 3.2.7 claim()

```
1. require !claimed[sender]
2. IF status == Resolved: payout = _payoutResolved(sender)
   ELSE IF status == Voided: payout = yesBalance + noBalance
   ELSE: revert "not claimable"
3. require payout > 0
4. claimed[sender] = true
5. collateral.safeTransfer(sender, payout)
6. emit Claimed(sender, payout)
```

#### 3.2.8 _payoutResolved(address user) — internal view

```
totalPool = yesPool + noPool
IF winningOutcome == 0:
  userStake = yesBalance[user]; winSideTotal = yesPool
ELSE:
  userStake = noBalance[user]; winSideTotal = noPool
IF userStake == 0 OR winSideTotal == 0: return 0
RETURN (userStake * totalPool) / winSideTotal
```

#### 3.2.9 事件

| 事件 | indexed 参数 | 非 indexed |
|------|--------------|------------|
| Bought | user | outcome, amount |
| Resolved | — | winningOutcome |
| Claimed | user | amount |
| MarketVoided | — | — |

### 3.3 MarketFactory（Phase 2）

**文件**：`contracts/MarketFactory.sol`

#### 3.3.1 状态变量

| 名称 | 类型 | 说明 |
|------|------|------|
| collateral | IERC20 immutable | 工厂级抵押代币 |
| oracle | address | **可变**；新市场使用当前值 |
| marketCount | uint256 | 已创建市场数 |
| markets | mapping(uint256=>address) | id → 市场地址 |

#### 3.3.2 createMarket(matchRef, question, endTime) — onlyOwner

**步骤**：

```
1. m = new PredictionMarket(
     address(collateral), oracle, address(this),
     matchRef, question, endTime)
2. marketId = ++marketCount
3. market = address(m); markets[marketId] = market
4. emit MarketCreated(marketId, market, matchRef, question, endTime)
5. return (market, marketId)
```

**跨合约**：新市场 `oracle` 字段 = 工厂**当前** `oracle`（非 Adapter 地址时，需将工厂 oracle 设为 Adapter 并在 Adapter 发交易 — **实际部署中 factory.oracle = OracleAdapter 地址**，Adapter 持有 ORACLE_ROLE 的 EOA 调 Adapter，Adapter 再调 market.resolve；market.oracle 应为 **Adapter 合约地址**）。

**部署设计**（deploy.js）：`Factory.deploy(usdc, adapterAddr)` → 市场的 `oracle` = OracleAdapter 合约。

#### 3.3.3 setOracle(address) — onlyOwner

```
require _oracle != 0
oracle = _oracle
（不影响已部署市场）
```

### 3.4 OracleAdapter（Phase 2）

**文件**：`contracts/OracleAdapter.sol`

#### 3.4.1 常量与状态

| 名称 | 值/类型 | 说明 |
|------|---------|------|
| ORACLE_ROLE | keccak256("ORACLE_ROLE") | 结算角色 |
| timelockDelay | uint256 | 秒 |
| factory | address | 记录用，链上逻辑未强制校验 |
| pending | mapping(address=>PendingResolve) | 每市场一条 pending |

**PendingResolve 结构**：

| 字段 | 类型 |
|------|------|
| outcome | uint8 |
| executeAfter | uint256 |
| active | bool |

#### 3.4.2 constructor(admin, _timelockDelay)

```
_grantRole(DEFAULT_ADMIN_ROLE, admin)
_grantRole(ORACLE_ROLE, admin)
timelockDelay = _timelockDelay
```

#### 3.4.3 requestResolve(market, outcome) — ORACLE_ROLE

```
1. require outcome <= 1
2. require IPredictionMarket(market).status() == 0
3. executeAfter = block.timestamp + timelockDelay
4. pending[market] = {outcome, executeAfter, active: true}
5. emit OracleResolveRequested(market, outcome, executeAfter)
```

#### 3.4.4 confirmResolve(market) — ORACLE_ROLE

```
1. p = pending[market]
2. require p.active
3. require block.timestamp >= p.executeAfter  // "timelock"
4. p.active = false
5. IPredictionMarket(market).resolve(p.outcome)
6. emit OracleResolveConfirmed(market, p.outcome)
```

#### 3.4.5 resolveNow(market, outcome) — ORACLE_ROLE

```
1. require timelockDelay == 0  // "use request+confirm"
2. require outcome <= 1
3. IPredictionMarket(market).resolve(outcome)
4. emit OracleResolveConfirmed(market, outcome)
```

#### 3.4.6 voidMarket(market) — ORACLE_ROLE

```
1. require status == 0
2. IPredictionMarket(market).voidMarket()
3. emit MarketVoided(market)
```

**跨合约调用链**：

```
Oracle EOA → OracleAdapter (ORACLE_ROLE)
  → IPredictionMarket.resolve / voidMarket
    → PredictionMarket (msg.sender == market.oracle == Adapter地址)
```

### 3.5 PredictionMarketV3（Phase 3 CPMM）

**文件**：`contracts/PredictionMarketV3.sol`

#### 3.5.1 状态变量（补充）

| 名称 | 类型 | 说明 |
|------|------|------|
| feeBps | uint16 | 买入手续费基点 |
| maxBetPerUser | uint256 | 0=不限 |
| marketStatus | Status | 同 status |
| reserveYes / reserveNo | uint256 | CPMM 储备 |
| totalLPSupply | uint256 | LP 总供应（记账） |
| collectedFees | uint256 | 累计 fee（不可提取） |
| lpBalance | mapping | LP 份额 |
| userBetTotal | mapping | 用户累计买入额 |

#### 3.5.2 seedReserves(perSide, lpRecipient) — only factory

```
1. require msg.sender == factory
2. require totalLPSupply == 0
3. _seedReserves(perSide, lpRecipient)
```

**_seedReserves 内部**：

```
total = perSide * 2
require collateral.balanceOf(this) >= total
reserveYes = reserveNo = perSide
lpBalance[lpRecipient] = total
totalLPSupply = total
emit LiquidityAdded(lpRecipient, total)
```

#### 3.5.3 buy(uint8 outcome, uint256 amountIn) — nonReentrant

```
1. require marketStatus == Open
2. require block.timestamp < endTime
3. require outcome <= 1 && amountIn > 0
4. require userBetTotal[sender]+amountIn <= maxBetPerUser OR maxBetPerUser==0
5. fee = amountIn * feeBps / 10000
6. net = amountIn - fee; collectedFees += fee
7. safeTransferFrom(sender, this, amountIn)
8. sharesOut = _swap(outcome, net)
9. userBetTotal[sender] += amountIn
10. yesBalance/noBalance += sharesOut
11. emit Bought(sender, outcome, amountIn, sharesOut)
```

#### 3.5.4 _swap(outcome, net) — internal

**买 Yes (outcome=0)**：

```
sharesOut = (net * reserveYes) / (reserveNo + net)
reserveNo += net
reserveYes -= sharesOut
return sharesOut
```

**买 No (outcome=1)**：

```
sharesOut = (net * reserveNo) / (reserveYes + net)
reserveYes += net
reserveNo -= sharesOut
return sharesOut
```

**不变量（近似）**：swap 前后 `reserveYes * reserveNo` 在整数精度下近似恒定；fee 不进入 swap（留在 collectedFees）。

#### 3.5.5 addLiquidity / removeLiquidity

**addLiquidity(amount)**：

```
transferFrom → half = amount/2
reserveYes += half; reserveNo += amount - half
lpBalance += amount; totalLPSupply += amount
```

**removeLiquidity(lpAmount)**：

```
yesOut = lpAmount * reserveYes / totalLPSupply
noOut = lpAmount * reserveNo / totalLPSupply
更新 reserve、lpBalance、totalLPSupply
transfer(yesOut + noOut)
```

#### 3.5.6 _claimResolved(user) — internal view

```
total = reserveYes + reserveNo
IF winningOutcome == 0:
  IF reserveYes == 0: return 0
  RETURN yesBalance[user] * total / reserveYes
ELSE:
  IF reserveNo == 0: return 0
  RETURN noBalance[user] * total / reserveNo
```

**Voided claim**：`payout = yesBalance[user] + noBalance[user]`（份额数量之和，非 token 原始投入）。

#### 3.5.7 getPoolState() — view

```
yesR = reserveYes; noR = reserveNo
total = yesR + noR
priceYesBps = total==0 ? 5000 : (noR * 10000) / total
```

### 3.6 MultiOutcomeMarket（Phase 3 多结果 parimutuel）

**文件**：`contracts/MultiOutcomeMarket.sol`

#### 3.6.1 状态变量

| 名称 | 类型 | 说明 |
|------|------|------|
| pool | uint256[] | 长度 outcomeCount；各 outcome 池 |
| stake | mapping(address=>mapping(uint8=>uint256)) | 用户各 outcome 净押注 |
| outcomeCount | uint8 | 2–8 |
| feeBps | uint16 | buy 时扣费 |

**无 factory immutable**（与 PMV3 差异）。

#### 3.6.2 constructor

```
require outcomeCount in [2,8]
初始化 pool[] 为 outcomeCount 个 0
```

#### 3.6.3 buy(outcome, amount)

```
1. require Open && timestamp < endTime  // "closed"
2. require outcome < outcomeCount && amount > 0
3. fee = amount * feeBps / 10000; net = amount - fee
4. transferFrom(full amount)
5. pool[outcome] += net; stake[sender][outcome] += net
6. emit Bought(sender, outcome, amount)
```

**注意**：fee 留在合约，**不**计入 pool/stake。

#### 3.6.4 claim() — Resolved

```
winPool = pool[winningOutcome]; require winPool > 0
total = sum(pool[i] for i in 0..outcomeCount-1)
payout = stake[sender][winningOutcome] * total / winPool
```

#### 3.6.5 claim() — Voided

```
payout = sum(stake[sender][i] for all i)
```

### 3.8 OracleAdapterV2

**文件**：`contracts/OracleAdapterV2.sol`

#### 3.8.1 Proposal 结构

| 字段 | 类型 |
|------|------|
| market | address |
| outcome | uint8 |
| approvals | uint256 |
| executed | bool |

#### 3.8.2 proposeResolve(market, outcome)

```
1. require outcome <= 7
2. require market.status() == 0
3. id = ++proposalCount
4. proposals[id] = {market, outcome, approvals: 0, executed: false}
5. _approve(id)  // 提议者自动投一票
6. emit ProposalCreated(id, market, outcome)
7. return id
```

#### 3.8.3 _approve(id) — internal

```
require !proposals[id].executed
require !approved[id][msg.sender]
approved[id][msg.sender] = true
proposals[id].approvals++
emit ProposalApproved(id, msg.sender)
IF approvals >= threshold: _execute(id)
```

#### 3.8.4 _execute(id) — internal

```
require !executed
executed = true
IPredictionMarket(market).resolve(outcome)
emit ProposalExecuted(id, outcome)
```

**threshold=1 时**：proposeResolve 单次调用即 _approve → 立即 _execute。


## 4. 核心算法

### 4.1 Parimutuel 赔付（PredictionMarket）

**公式**：

\[
\text{payout}(u) = \frac{\text{stake}(u, w) \times (\text{yesPool} + \text{noPool})}{\text{pool}(w)}
\]

其中 \(w\) = winningOutcome，stake 为 user 在获胜侧余额。

**示例**（与测试一致）：

| 用户 | Yes | No | 池 Yes | 池 No |
|------|-----|-----|--------|-------|
| Alice | 100 | 0 | 100 | 100 |
| Bob | 0 | 100 | | |

winningOutcome=0 → Alice payout = 100×200/100 = **200**（6 decimals 单位）。

### 4.2 Parimutuel 多结果（MultiOutcomeMarket）

\[
\text{payout}(u) = \frac{\text{stake}(u, w) \times \sum_i \text{pool}[i]}{\text{pool}[w]}
\]

fee 部分不在 pool 中，赢家分配的是**扣费后**池子总和。

### 4.3 CPMM 交换（PredictionMarketV3）

**买 Yes**，投入 net 到 No 侧储备：

```
sharesOut = net * R_yes / (R_no + net)
R_no' = R_no + net
R_yes' = R_yes - sharesOut
```

**隐含 Yes 价格（基点）**：

```
priceYesBps = R_no / (R_yes + R_no) * 10000
```

买 Yes 增加 R_no、减少 R_yes → priceYesBps 上升。

### 4.4 LP 份额赎回

```
yesOut = lpAmount * R_yes / totalLPSupply
noOut = lpAmount * R_no / totalLPSupply
用户收到 collateral = yesOut + noOut
```

### 4.5 整数除法与 dust

所有除法为 Solidity 整数除（向下取整）。余数留在合约内，无 sweep 函数。

## 5. Oracle 流程详细步骤

### 5.1 Phase 2 — timelock > 0

```
T0: Oracle.requestResolve(M, outcome)
    → pending[M] = {outcome, now+delay, active}
T1: Oracle.confirmResolve(M)
    → IF now < executeAfter: REVERT "timelock"
T2: confirm 成功 → M.resolve(outcome)
```

### 5.2 Phase 2 — timelock = 0

```
Oracle.resolveNow(M, outcome)
  → M.resolve(outcome)
（禁止在 timelock>0 时使用 resolveNow）
```

### 5.3 Phase 2 — void

```
Oracle.voidMarket(M)
  → M.voidMarket()
用户 M.claim() → 退还 yesBalance+noBalance（PM）或份额和（PMV3）
```

### 5.4 Phase 3 — multisig

```
O1.proposeResolve(M, o) → id=1, approvals=1
IF threshold > 1:
  O2.approveResolve(1) → approvals=2 >= threshold
  → _execute → M.resolve(o)
```

### 5.5 Backend OracleClient 对齐

Backend `internal/blockchain/oracle_client.go` 封装：

| 方法 | Adapter 函数 | timelock=0 |
|------|--------------|------------|
| RequestResolve | requestResolve | — |
| ConfirmResolve | confirmResolve | — |
| ResolveNow | resolveNow | ✓ |
| VoidMarket | voidMarket | — |

**Phase 3**：当前 Backend 仍绑定 OracleAdapter ABI；接 Phase 3 需增加 OracleAdapterV2 的 proposeResolve/approveResolve 绑定。

## 6. 事件与 Indexer 解码

### 6.1 MarketCreated（MarketFactory）

**签名**：`MarketCreated(uint256 indexed marketId, address indexed market, bytes32 indexed matchRef, string question, uint256 endTime)`

| Topic | 内容 |
|-------|------|
| topics[0] | 事件 keccak 签名 |
| topics[1] | marketId |
| topics[2] | market 地址 |
| topics[3] | matchRef |

**Backend Indexer**：Unpack data → 写 markets 表；matchRef 映射 external_id。

### 6.2 Bought（PredictionMarket）

**签名**：`Bought(address indexed user, uint8 outcome, uint256 amount)`

| Topic | 内容 |
|-------|------|
| topics[1] | user 地址 |

**Backend**：InsertTrade + AddTrade(positions)。

```
main():
```
