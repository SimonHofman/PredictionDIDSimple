## 1. 引言

### 1.1 编写目的

本文档在需求规格（01）与概要设计（02）基础上，给出 Frontend 的**详细设计**：包括配置对象、API/链上服务函数规格、页面 state 与事件处理伪代码、组件 props、路由表、存储键与错误处理，供开发、联调、测试直接对照实现。

### 1.2 文档约定

- **路径**：除非注明，均相对于 `frontend/` 目录。
- **地址**：UI 展示为缩短格式；链上/API 使用完整 `0x` 地址。
- **金额**：用户输入为十进制 mUSDC 字符串；链上为 `bigint`（6 decimals）；API 为 string 最小单位。
- **时间**：API 字段 `*_at`、`*_time` 为 ISO8601/RFC3339；展示用 `toLocaleString()`。
- **market_type**：Backend 返回值；`BINARY_V3`、`MULTI` 或缺省（Phase 2 parimutuel）。

## 4. API 服务层详细规格

**文件**：`src/services/api.js`

**常量**：`TOKEN_KEY = 'prediction_jwt'`

### 4.1 JWT 辅助函数

| 函数 | 行为 |
|------|------|
| getToken() | `localStorage.getItem(TOKEN_KEY)` |
| setToken(token) | localStorage 写入 |
| clearToken() | localStorage 删除 |

### 4.2 request(path, options) — 内部

**伪代码**：

```
headers = { Accept: application/json }
IF options.body: headers.Content-Type = application/json
headers.merge(options.headers)
IF getToken(): headers.Authorization = Bearer {token}

res = fetch(config.apiUrl + path, { ...options, headers })
data = await res.json() catch {}
IF !res.ok: throw Error(data.error || `HTTP ${res.status}`)
RETURN data
```

## 6. 认证 Hook 详细算法

**文件**：`src/hooks/useAuth.js`

### 6.1 依赖 Hook

| Hook | 用途 |
|------|------|
| useAccount() | address, chainId, isConnected |
| useSignMessage() | signMessageAsync |

### 6.2 返回值

| 字段 | 类型 | 说明 |
|------|------|------|
| isConnected | boolean | wagmi |
| address | string \| undefined | 当前账户 |
| token | string \| null | getToken() 每次 render 读取 |
| isAuthenticated | boolean | Boolean(token) |
| login | async () => void | SIWE 流程 |
| logout | () => void | clearToken + reload |
| loading | boolean | 登录中 |
| error | string \| null | 错误消息 |

### 6.3 login() 逐步逻辑

```
1. IF !address || !chainId: RETURN
2. setLoading(true); setError(null)
3. message = new SiweMessage({
     domain: config.siweDomain,
     address,
     statement: 'Sign in to Prediction DID World Cup',
     uri: config.siweUri,
     version: '1',
     chainId,
     nonce: Math.random().toString(36).slice(2),
   })
4. prepared = message.prepareMessage()
5. signature = await signMessageAsync({ message: prepared })
6. res = await siweAuth(prepared, signature)
7. setToken(res.token)
8. did = `did:pkh:eip155:${chainId}:${address.toLowerCase()}`
9. TRY bindDid(did, signature) CATCH ignore
10. window.location.reload()
11. ON ERROR: setError(e.message)
12. FINALLY: setLoading(false)
```

**设计说明**：bindDid 复用 SIWE 同一 signature；Backend 若校验 DID 专用签名可能失败（已知 MVP 行为）。

### 6.4 logout()

```
clearToken()
window.location.reload()
```

## 7. 页面详细设计

### 7.1 Home（pages/Home.jsx）

**State**：

| 变量 | 初值 | 说明 |
|------|------|------|
| apiStatus | `'checking'` | online/offline |
| matches | `[]` | 比赛列表 |
| error | null | 错误消息 |

**useEffect（mount）**：

```
TRY:
  await getHealth() → apiStatus = 'online'
  res = await listMatches({ limit: 10 })
  matches = res.items || []
CATCH:
  apiStatus = 'offline'; error = e.message
```

**渲染逻辑**：

```
upcoming = matches.filter(m => status in SCHEDULED, LIVE)
展示 API 状态 CSS: status-ok | status-error
grid 卡片 Link → /matches/:id
```

### 7.2 Markets（pages/Markets.jsx）

**State**：`items`, `error`

**useEffect**：`listMarkets({ limit: 50 })` → setItems

**展示**：question、match 球队、formatUsdc(yes/no_pool)、status

### 7.3 MatchDetail（pages/MatchDetail.jsx）

**Params**：`id` from useParams()

**State**：`data`, `error`

**useEffect**：`getMatch(id)` → setData

**渲染**：match 字段 + markets 列表 Link → `/markets/:mk.id`

### 7.4 MarketDetail（pages/MarketDetail.jsx）

**State**：

| 变量 | 初值 | 说明 |
|------|------|------|
| data | null | getMarket 响应 |
| amount | `'10'` | 下注金额输入 |
| outcome | 0 | 选中 outcome |
| pool | null | 链上/API 池 |
| tx | `{ status, error, hash }` | 交易状态 |

**refresh()**：

```
res = await getMarket(id)
setData(res)
IF res.market.market_address:
  readMarketStatus(addr)  // 结果未存 state，仅触发 RPC
  IF market_type === 'BINARY_V3':
    setPool(await readPoolStateV3(addr))
  getMarketPool(id).then(setPool).catch(() => {})
```

**onBuy()**：

```
GUARD: isConnected && market && collateral
GUARD: !(access.requires_vc && !access.allowed)
setTx pending
TRY:
  amt = parseUsdc(amount)
  approveUsdc(collateral, market.market_address, amt)
  SWITCH market.market_type:
    'BINARY_V3' → buyV3
    'MULTI'     → buyMulti
    default     → buyOutcome
  setTx success + receipt.transactionHash
  await refresh()
CATCH:
  setTx error (e.shortMessage || e.message)
```

**displayStatus**：

```
IF market.match?.status === 'ORACLE_PENDING' → 'ORACLE_PENDING'
ELSE → market.status
```

**下注区显示条件**：

```
market.status === 'OPEN' && (!access?.requires_vc || access.allowed)
```

**pool 价格展示**：

| 来源 | 字段 | 公式 |
|------|------|------|
| 链上 V3 | pool.priceYesBps | Number/100 + '%' |
| API | pool.price_yes_bps | 同上 |

### 7.5 Me（pages/Me.jsx）

**State**：`items`, `error`, `tx`

**load()**：`myPositions()` → items（需 isAuthenticated）

**useEffect**：`if (isAuthenticated) load()`

**onClaim(marketAddress)**：

```
setTx pending
TRY:
  receipt = await claimMarket(marketAddress)
  setTx success + hash
  load()
CATCH: setTx error
```

**Claim 按钮条件**：

```
(p.market.status === 'RESOLVED' || p.market.status === 'VOID')
&& !p.claimed
```

**限制**：claimMarket 固定 PredictionMarket ABI；V3/Multi 市场 claim 可能 revert。

### 7.7 Stats（pages/Stats.jsx）

### 7.8 Liquidity（pages/Liquidity.jsx）

**State**：`markets`, `selected`, `pool`, `amount`('100'), `tx`

**useEffect 1**：`listMarkets({ status: 'OPEN' })` → 默认 selected=第一个 id

**useEffect 2**：selected 变化 → getMarketPool(selected)

**onAdd()**：

```
m = markets.find(id === selected)

GUARD: m && isConnected && collateral
TRY:

  addLiquidityV3(m.market_address, amt)

CATCH: setTx e.message
```

**注意**：未校验 market_type；对非 V3 市场会链上失败。

### 11.3 链上错误

| 来源 | 处理 |
|------|------|

| e.message | 回退 |

**常见链上 revert 用户文案**（钱包返回）：

| 模式 | 含义 |
|------|------|
| ended / closed | 已过截止时间 |
| not open | 市场已结算 |
| insufficient allowance | 需 approve |
| nothing to claim | 无领取额度 |
