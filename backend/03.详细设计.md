## 1. 引言

### 1.1 编写目的

本文档在需求规格（01）与概要设计（02）基础上，给出 Backend 的**详细设计**：包括核心类型定义、接口报文、数据库字段、关键算法步骤、时序与错误码，供开发、联调、测试直接对照实现。

### 1.2 文档约定

- **路径**：除非注明，均相对于 `backend/` 目录。
- **地址**：以太坊地址在 DB 中统一存小写；API 比较时大小写不敏感。
- **金额**：链上 numeric 在 DB 中为 `NUMERIC(78,0)`，API JSON 中为 **string**（十进制整数字符串）。
- **时间**：DB 为 `TIMESTAMPTZ`；API JSON 为 RFC3339。

## 2. 进程入口详细设计（cmd）

### 2.1 cmd/api — 主服务

**文件**：`cmd/api/main.go`

**启动伪代码**：

```
main():
  cfg = config.Load()                    // 失败 → Fatalf
  ctx, cancel = WithCancel(background)
  migrationsPath = resolve("migrations" | "backend/migrations")
  database.RunMigrations(DATABASE_URL, migrationsPath)
  pool = database.NewPool(ctx, DATABASE_URL)
  rdb = redis.NewClient(REDIS_URL)         // 失败 WARN，继续
  chain = blockchain.New(RPC, CHAIN_ID)
  chain.StartBackgroundPing(ctx)         // 30s ticker

  if FactoryAddress != "":
    go indexer.New(...).Run(ctx)         // 内嵌 Indexer goroutine

  oracleChain = nil
  if OracleAdapterAddress && OraclePrivateKey:
    oracleChain = blockchain.NewOracleClient(...)  // 失败 WARN

  srv = server.New(Dependencies{...})
  go srv.ListenAndServe()
  wait SIGINT/SIGTERM
  srv.Shutdown(10s timeout)
```

**设计参数**：

| 参数 | 值 |
|------|-----|
| 迁移 | 启动时自动 Up |
| Shutdown 超时 | 10s |
| Indexer | 与 HTTP 同进程 goroutine，共享 ctx |
| WriteTimeout | 0（server.New，支持 SSE） |
| ReadTimeout | 15s |

### 2.2 cmd/indexer

**文件**：`cmd/indexer/main.go`

与 `cmd/api` 内嵌逻辑相同，但 **Indexer 为唯一主进程**；无 HTTP Server。适用于 Indexer 与 API 分离部署。

### 2.3 cmd/oracle

**文件**：`cmd/oracle/main.go`

**依赖构造顺序**：

```
config.Load → database.NewPool
→ OracleJobRepo, MatchRepo, MarketRepo
→ wcprovider.NewDual(primary, secondary)
→ blockchain.NewOracleClient (可选，失败 WARN)
→ alert.New(ALERT_WEBHOOK_URL)
→ oracle.NewWorker(...).Run(ctx)
```

**行为**：`chain == nil` 时 Worker 仍运行，但 `processDue` 跳过链上调用。

### 2.4 cmd/sync / seed / migrate / reconcile

| 入口 | 核心调用 | 退出条件 |
|------|----------|----------|
| sync | `DualProvider.SyncPrimary` | 失败 Fatal |
| seed | `RunMigrations` + `MockProvider.Sync` | 失败 Fatal |
| migrate | `RunMigrations` only | 失败 Fatalf |
| reconcile | `run(ctx, pool, cfg)` | 缺 CollateralAddress Fatal |

**reconcile.run 算法**：

```
FOR each market IN (status IN ('OPEN','RESOLVED')):
  db_total = yes_pool + no_pool  // numeric
  chain_bal = ERC20Balance(CollateralAddress, market_address)
  IF chain_bal err: TRY EthRPCFallback
  delta = chain_bal - db_total
  INSERT reconciliation_runs(...)
  IF delta != 0: LOG WARN
```

### 3.8 vc.Issuer

**Issue 输出 JSON 结构**（固定字段）：

```json
{
  "@context": ["https://www.w3.org/2018/credentials/v1"],
  "type": ["VerifiableCredential", "<Type>"],
  "issuer": { "id": "did:web:prediction-did.local:issuer", "name": "..." },
  "issuanceDate": "<RFC3339>",
  "expirationDate": "<RFC3339>",
  "credentialSubject": { "id": "<SubjectDID>", ...claims },
  "proof": {
    "type": "HMAC-SHA256",
    "proofPurpose": "assertionMethod",
    "verificationMethod": "did:web:prediction-did.local:issuer#key-1",
    "proofValue": "<base64 hmac>"
  }
}
```

**Verify 步骤**：

1. Unmarshal JSON
2. 提取 proof.proofValue，删除 proof 后重新 Marshal payload
3. HMAC 比对
4. 检查 expirationDate 未过期

## 4. HTTP API 详细规格

### 4.1 通用约定

**Base URL**：`http://{host}:{HTTP_PORT}`，默认 `http://localhost:8080`

**错误响应**（4xx/5xx）：

```json
{ "error": "human readable message" }
```

**分页 Query**（matches/markets）：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| status | string | 空=全部 | 状态过滤 |
| limit | int | 20 | ≤0 时 Repo 用 20 |
| offset | int | 0 | 偏移 |

### 4.2 健康与监控

#### GET /health

- **鉴权**：无
- **响应 200**：

```json
{ "status": "ok" }
```

#### GET /ready

- **鉴权**：无；Geo/RateLimit 豁免
- **响应 200**（DB 可用）：

```json
{
  "status": "ready",
  "db_ok": true,
  "redis_ok": true,
  "rpc_ok": true,
  "chain_id": 31337
}
```

- **响应 503**（DB Ping 失败）：`status: "not ready"`, `db_ok: false`, `db_error: "..."`

#### GET /metrics

- **Content-Type**：`text/plain; version=0.0.4`
- **示例**：

```
oracle_jobs_pending 2
oracle_jobs_manual_review 1
oracle_jobs_confirmed 10
oracle_jobs_failed 0
```

#### GET /events/scores（SSE）

- **Header**：`Content-Type: text/event-stream`
- **行为**：每 5s 发送 `data: {"items":[...matches...]}\n\n`
- **失败**：ResponseWriter 不支持 Flusher → 500

### 4.3 认证

#### POST /auth/siwe

**请求**：

```json
{
  "message": "<SIWE EIP-4361 message string>",
  "signature": "0x..."
}
```

**处理步骤**：

1. JSON Decode → 失败 400 `invalid body`
2. `auth.VerifySIWE(SIWEConfig{Domain, URI}, message, signature)` → 失败 401
3. `Users.UpsertByAddress(addr)` → 失败 500
4. `IssueJWT(secret, addr, 24h)` → 失败 500
5. 200 返回 token + user

**响应 200**：

```json
{
  "token": "<JWT>",
  "user": { "id": 1, "address": "0x...", "did": null }
}
```

#### POST /users/bind-did

- **鉴权**：JWT Bearer
- **请求**：

```json
{
  "did": "did:pkh:eip155:31337:0x...",
  "signature": "0x..."
}
```

- **校验**：DID 必须等于 `did:pkh:eip155:{ChainID}:{lower(address)}`
- **响应 200**：`{ "user": { ... } }`

#### GET /me/positions

- **鉴权**：JWT
- **响应 200**：`{ "items": [ Position, ... ] }`

#### GET /users/me/credentials

- **鉴权**：JWT
- **响应 200**：`{ "items": [ Credential, ... ] }`（未 revoke 且未过期）

### 5.2 关键 SQL 模式

**MarketRepo.InsertFromChain**：

```sql
INSERT INTO markets (...)
VALUES (...)
ON CONFLICT (market_address) DO UPDATE SET match_id = EXCLUDED.match_id
RETURNING id
```

**PositionRepo.AddTrade**：

```sql
INSERT INTO positions (market_id, user_address, yes_amount, no_amount, ...)
VALUES (...)
ON CONFLICT (market_id, user_address) DO UPDATE SET
  yes_amount = positions.yes_amount + EXCLUDED.yes_amount,  -- 或 no 侧
  updated_at = NOW()
```

**CredentialRepo.HasValidType**：

```sql
SELECT EXISTS(
  SELECT 1 FROM credentials
  WHERE LOWER(user_address) = LOWER($1)
    AND credential_type = $2
    AND revoked = FALSE
    AND expires_at > NOW()
)
```

## 6. Indexer 详细算法

### 6.1 主循环

```
Run(ctx):
  IF FactoryAddress == "": LOG skip; RETURN nil
  ticker = IndexerPollSeconds
  LOOP:
    poll(ctx, factoryAddr)   // 错误仅 LOG
    SELECT ctx.Done | ticker
```

### 6.2 poll 单轮

```
last = state.GetLastBlock()
IF last == 0 AND IndexerStartBlock > 0:
  last = IndexerStartBlock - 1
head = client.BlockNumber()
IF last >= head: RETURN
from = last + 1
to = min(head, from + 2000)
scanFactory(factory, from, to)
scanMarkets(from, to)
state.SetLastBlock(to, FactoryAddress)
```

### 6.3 handleMarketCreated

**Topics 布局**（MarketCreated）：

| Index | 内容 |
|-------|------|
| Topics[0] | 事件签名 |
| Topics[1] | marketId |
| Topics[2] | market 地址 |
| Topics[3] | matchRef bytes32 |

**Data**：Unpack → question (string), endTime (uint256)

**matchRef 映射表**（硬编码）：

| external_id | keccak256(external_id) 匹配 matchRef |
|-------------|--------------------------------------|
| wc-2026-semi-001 | ✓ |
| wc-2026-semi-002 | ✓ |
| wc-2026-final-001 | ✓ |
| 其他 | 使用 matchRef hex 作为 external_id |

### 6.4 handleBought

```
Unpack Bought → outcome, amount
user = Topics[1]
InsertTrade(marketID, txHash, logIndex, block, user, outcome, amount)
AddTrade(marketID, user, outcome, amount)
```

**outcome 映射**：0 → yes_amount；非 0 → no_amount。

### 6.5 handleResolved / handleClaimed

- **Resolved**：`UpdateResolved(address, outcome, "0", "0")`
- **Claimed**：`SetClaimed(marketID, user from Topics[1])`

### 6.6 scanMarkets 性能说明

- 每次 poll 加载最多 **500** 个市场（List limit=500）
- 每个市场单独 FilterLogs → 市场数量大时 RPC 压力高（已知限制）

## 7. Oracle Worker 详细算法

### 7.1 tick

```
tick(ctx):
  enqueueFinished(ctx)  // 错误向上返回
  processDue(ctx)
```

### 7.2 enqueueFinished

```
matches = MatchRepo.List(status=FINISHED, limit=100)
FOR each match m:
  markets = MarketRepo.ListOpenByMatchID(m.ID)
  FOR each market mk:
    IF HasActiveForMarket(mk.ID): CONTINUE
    executeAfter = now + OracleCooldownMinutes
    OracleJobRepo.Create(mk.ID, &m.ID, executeAfter)
    MatchRepo.SetStatus(m.ID, ORACLE_PENDING)
```

### 7.3 processJob

```
IF job.MatchID == nil: RETURN nil
match = GetByID(*job.MatchID)
pri, sec, ok, err = dual.CompareScores(match.ExternalID)
UPDATE job fields: primary_*, secondary_*

IF !ok:
  UpdateStatus(manual_review, error="dual source score mismatch or missing")
  alerts.Send("oracle_manual_review", ...)
  RETURN nil

market = GetByID(job.MarketID)
rule = market.ResolutionRule OR "HOME_WIN"
outcome = OutcomeFromRule(rule, pri.HomeScore, pri.AwayScore)

IF OracleTimelockSeconds <= 0:
  txHash = chain.ResolveNow(marketAddress, outcome)
ELSE:
  txHash = chain.RequestResolve(...)
  chain.WaitMined(txHash)
  sleep(OracleTimelockSeconds)
  txHash = chain.ConfirmResolve(marketAddress)

IF err:
  UpdateStatus(failed, error=err.Error())
  alerts.Send("oracle_failed", ...)
  RETURN err

chain.WaitMined(txHash)
UpdateStatus(confirmed, tx_hash=txHash, proposed_outcome=outcome)
Markets.UpdateResolved(address, outcome, "0", "0")
Matches.SetStatus(RESOLVED)
```

### 7.4 OutcomeFromRule

| rule | 条件 | outcome |
|------|------|---------|
| OVER_25 | home+away > 2 | 0 |
| OVER_25 | else | 1 |
| HOME_WIN（默认） | home > away | 0 |
| HOME_WIN | else | 1 |

### 7.5 DualProvider.CompareScores

```
primaryMap = load(primaryPath)
secondaryMap = load(secondaryPath)
IF either missing externalID: RETURN match=false
match = (home, away 完全一致)
```

**load 过滤**：仅包含 `home_score` 与 `away_score` 均非 nil 的 JSON 条目。

## 8. 认证与 VC 详细设计

### 8.1 JWT

**算法**：HS256

**Claims**：

```json
{
  "address": "0x...",
  "exp": 1234567890,
  "iat": 1234567890
}
```

**Middleware 流程**：

```
Authorization header
IF NOT HasPrefix("Bearer "): 401 unauthorized
token = TrimPrefix
ParseJWT(secret, token)
IF error: 401 invalid token
ctx = WithValue(AddressKey, claims.Address)
next.ServeHTTP
```

### 8.2 AdminMiddleware

```
IF apiKey == "": 503 admin not configured
key = Header X-Admin-Key OR TrimPrefix Bearer
IF key != apiKey: 403 forbidden
```

### 8.3 SIWE VerifySIWE 步骤

1. `siwe.ParseMessage(message)`
2. `msg.GetDomain() == cfg.Domain`
3. `msg.GetURI().String() == cfg.URI`
4. 若有过期时间且已过期 → error
5. `msg.Verify(signature, &domain, nil, nil)`
6. 返回 `lower(msg.GetAddress().Hex())`

### 8.4 GeoBlock 豁免路径

| 路径前缀/精确 | 豁免 |
|---------------|------|
| /health, /ready | ✓ |
| /metrics | ✓ |
| /compliance/restricted | ✓ |
| /events/ | ✓（前缀） |

### 9.1 RateLimit（ipLimiter）

**数据结构**：

```
counts: map[ip]int
windowAt: time.Time

**allow(ip)**：

```
IF now - windowAt > 1 minute:
  counts = {}
  windowAt = now
counts[ip]++
RETURN counts[ip] <= limit

**超限响应**：429，`{"error":"rate_limited"}`（http.Error 写入）
